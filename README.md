# Professional Portfolio - Alvin Monir

A premium, dynamic portfolio built with Next.js 15, TypeScript, and MongoDB, featuring a sophisticated project management system and advanced UI/UX.

## 🚀 Key Features

### 🖼️ Advanced Project Gallery
- **Multi-Image Support**: Showcase projects with a main thumbnail and an unlimited gallery of supporting images.
- **Interactive Sliders**: Premium image sliders both on the public site and in the admin preview modal.
- **Category Management**: Organized by "Custom Code" and "Wix/No-Code" projects.

### 🔗 Router-Based Modals
- **Parallel & Intercepting Routes**: Seamless navigation that opens project details in a modal while keeping the home page context.
- **Shareable URLs**: Direct links (e.g., `/projects/ID`) open as dedicated full-page views, perfect for sharing on social media or in resumes.

### 🛠️ Sophisticated Admin Panel
- **Real-time Management**: Add, edit, and delete projects and skills instantly.
- **Cloudinary Integration**: Robust image uploading system for thumbnails and galleries.
- **Smart Forms**: Conditional logic that hides or shows fields (like GitHub links) based on the project category.

### 🎨 Premium UI/UX
- **Dark Mode**: Fully responsive, high-fidelity dark and light themes.
- **Framer Motion**: Smooth animations and transitions throughout the application.
- **Modern Tech Stack**: Built with Next.js 15, Tailwind CSS, Redux, and MongoDB.

## 💻 Tech Stack
- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Framer Motion.
- **State Management**: Redux Toolkit.
- **Backend**: Next.js API Routes, Server Actions.
- **Database**: MongoDB.
- **Storage**: Cloudinary (Image hosting).

## 🛠️ Getting Started

First, install dependencies:
```bash
npm install
```

Set up your environment variables:
```env
MONGODB_URI=your_mongodb_uri
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
